# git-demo

用于验证本机 Git 环境是否配置正确的演示仓库。

## 环境

- Git: 2.56.0
- 编辑器: VS Code
- 默认分支: main

## 验证项

- [x] `git init` 创建仓库
- [x] `git add` / `git commit` 提交
- [x] 中文文件名与内容正常
- [ ] 推送到 GitHub

## 常用命令速查

```bash
git st          # 查看状态
git lg          # 图形化提交历史
git ci -m "说明" # 提交
git last        # 看最后一次提交
```
